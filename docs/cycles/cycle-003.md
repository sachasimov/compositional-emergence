## Work item for immediate continuation
Develop an exploratory exact counterexample to the idea that recurrence implies predictive compressibility, using finite binary trajectories. A length-n arbitrary bitstring repeating unchanged is perfectly persistent but the ensemble requires n bits to identify its state; a constant or low-dimensional target can be compressed without identifying the individual. Compare a redundant ensemble of n equal bits (one bit suffices). This distinguishes state compression from recurrence and future target selection. It is an analytic sanity check, not a CA detector result or confirmation of H4.
