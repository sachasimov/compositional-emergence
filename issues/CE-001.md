# CE-001 — Establish trusted CA simulations and detection benchmark

**Type:** Research infrastructure / method validation

## Objective
Build a reproducible benchmark distinguishing known persistent configurations from empty and nonpersistent dynamics, without treating visual complexity as evidence for emergence.

## Tasks
- [x] Implement ECA and Conway Life with declared periodic boundaries.
- [x] Verify Life block, blinker, glider, empty control and ECA rule 90.
- [x] Implement narrow exact-translational-recurrence assay.
- [ ] Build benchmark sets with positive and negative labels for structures, clutter and collisions.
- [ ] Develop a detector for objects from spontaneous trajectories.
- [ ] Measure precision/recall and false positives across seeds, densities, windows and boundary conditions.
- [ ] Generate versioned experiment manifests, figures and a methods report.
- [ ] Obtain independent code and scientific review.

## Acceptance criteria
1. Tests pass with documented run commands.
2. Detector assumptions and blind spots are explicit.
3. Predefined benchmark and held-out cases are archived.
4. Results include uncertainty, failures and negative controls.
5. Independent reviewers can rerun and audit every finding.

## Out of scope
Universal emergence claims, atom/molecule predictions, and engineered universal computers counted as spontaneous cumulative organization.
