# Recovery pilot — exploratory results
Frozen protocol 292c0c1; source 3f1c713; archive 97219e0. Executed committed run function in JS isolate; standalone Node and repository pytest not run; independent audit pending. All five prespecified checks passed.
Seven fixtures: 29 single deletions, 75 pair deletions, 94 halo additions (198 interventions). Isolated block: 4/4 single deletions recover at t1; 0/6 pair deletions recover by t8; positive contrast on all six pairs. Distant blocks: 8/8 single deletions recover, 16/28 pair deletions recover (all cross-block pairs); all 12 within-block pairs fail and have positive contrast. Graph recovers two four-cell groups. Nearby blocks: 4/8 singles and 8/28 pairs recover; groups [2,1,1,2,1,1]. Blinker and glider: no single or pair deletion recovers; graph returns singletons. Empty and singleton additions recover to empty, not evidence of structural resilience. All halo additions to the other fixtures fail to recover by t8. Geometry matches isolated/distant block groups and outperforms the recovery graph on nearby blocks, blinker and glider; no general detector advantage.
D=F(ij)-F(i)-F(j)>0 selects only cases where both singles recover but the pair fails. This is a specific synergistic failure contrast, not a general causal dependence measure. Global exact recovery is strict and misses phase/translation equivalence; intervention distribution matters. No actual predictive compression or MDL gain measured, no H4-H7 confirmation.
