Frozen protocol d185fae; implementation 275c750. Executed committed run function in JS isolate. All 3,200 flips (25,600 evolution steps), eight baselines and 32 horizon summaries archived under causal-pilot/. Standalone Node and repository pytest not run; independent audit pending. Two of four checks failed: isolated block connected by h2, distant blocks separate into exactly two groups. Panel and empty abstention passed.

At h4 weak/mutual component sizes: empty []; isolated block [1,1,1,1]; distant blocks eight singletons; nearby blocks [1,4,1,1,1]; blinker [3]; distant blinkers [3,3]; glider [5]; singleton [1]. Nearby blocks weak graph merges all eight at h8 while mutual components remain fragmented. Singleton dies by t1, but graph still returns a singleton candidate; not a persistence detector. Geometry outperforms this response criterion on isolated static blocks; no general advantage established.

Mechanism: deleting any one live cell from isolated 2x2 block leaves three live cells which regenerate the missing cell on next step; all baseline differences vanish. A zero response after t0 does not imply absent causal dependence. This is a counterexample to the specific single-deletion propagation criterion, not to causal individuation generally. The protocol's dead-site flips were recorded but not used for graph selection. Higher-order interventions or recovery signatures may distinguish stable coherent units, subject to matched controls, intervention budget and support/model costs. Compare destructive versus restorative responses; use pair deletion and add-one controls, check background and unrelated groups, and distinguish robustness from trivial insensitivity. Do not change frozen metrics retrospectively. No H4–H7 confirmation, Stage C or independent audit. Next: independent review of stacked pilots and preregistered robustness-aware detector.
