## Exact local argument (pending review)
Let B_n denote a finite block 4^n surrounded on the infinite typed line by zeros, centered on its support; B_0 is the zero line. Let F be the typed radius-one map derived by enumerating six-bit neighborhoods. An initial 8^n becomes B_n after one step. For n>=4, the only nonzero output after F(B_n) is 5 0 4^(n-2) 0 1, starting one site left of the original block. The next step leaves B_(n-4), inset by two sites on either end. This follows directly from the radius-one lookup (interior 444->4, edges 044/440->0, exterior 004->5,400->1; 040->3 only relevant to singleton; the outgoing 5/1 and adjacent sites disappear on the next step). Base cases from the same map: B_0 stays empty; B_1: 4 -> 531 -> 175 -> 60302, thereafter isolated left/right movers separate from the central alpha; B_2: 44 -> 5001 -> 26 -> 88 -> 44; B_3: 444 -> 50401 -> 3 -> 888 -> 444. For B_1, the next four phases have outward separation and a repeat of the center phase with movers four sites farther out, so future isolation follows by induction. Thus reduction and base cycles imply the table for all positive n in this ideal isolated-domain ensemble, if the label transcription and local proof are correct. Candidate times: n=4k (k>=1) empty at t=2k+1 from initial 8s; n=4k+1 has separated LAR by t=2k+4; n=4k+2 and 4k+3 are isolated B/A at t=2k+1. These are not claims about arbitrary environments or collision histories. Example n=4 gives 8888 -> 4444 -> 504401 -> empty, not beta. ## Central question and limits
The endpoint class for these four residue classes requires only two bits with a known isolated-block context and uniform residues; timing, position, initial extent, and reaction to a new perturbation are different targets. A fixed-radius instantaneous local classifier assigning final class to every interior site cannot work for arbitrary n: arbitrarily long runs with different residues have identical all-8 neighborhoods at interior sites but distinct eventual classes. This is a simple locality counterexample, compatible with the paper's buffering argument; does not imply that every predictive model requires a queue, or that classifying the residue globally requires unbounded memory (a modulo-four counter suffices). Counting/block boundary costs and observation time matter, and external coupling invalidates the isolated-context proof. The family has an extremely small endpoint code but only four known outcomes; no new particle class is generated within these examples. This refines H6 measurement, not evidence for or against conditional incremental predictive utility. Neither type assignment nor the counterexample establishes causal autonomy or spontaneous multigeneration composition. Reflection swaps the movers and preserves residue; translation is irrelevant to outcome type but not location. No chemical kinetics interpretation.
