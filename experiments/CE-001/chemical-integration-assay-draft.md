# Chemical integration assay — draft, not frozen or executed
Aim: distinguish coexistence, functional integration and recursive composition without redefining established RAF/COT concepts. Complement AlChemy replication, not substitute for it. No new confirmatory execution before independent preflight.
Analytic control A: food f,g; reactions f->a catalyzed by a and g->b catalyzed by b. Each is a RAF and union a RAF. No cross-catalysis. Control B: add reaction a+b->c catalyzed by c (food-generated structurally, initiation may require uncatalyzed events); union can contain novel product but no claim of viable integration without kinetics. Control C: specify cross-catalyzed replenishment plus loss terms and a novel jointly supported product; choose explicit resource, rate and perturbation model prospectively; compare to A/B and competition controls matched on size, food, reaction count and abundance. These are engineered analytic examples, not spontaneous discoveries. Verify COT flux feasibility separately; RAF and COT need not coincide.
Define endpoints before evaluation: persistence of both parent functional signatures; new product absent from either isolated parent control; cross-parent ancestry; contribution to combined system maintenance using matched selective cross-reaction ablation versus within-reaction and resource controls. Mutual dependence of entire parents is not required if novel combined function depends on both. Separate quantitative joint function, parent viability, and product persistence; record asymmetry and ambiguous cases. Recursion requires subsequent verified productive event, not set inclusion. Use same fixed resource budgets, kinetic assumptions and sampling horizons. Parent pairs are dependent: split by parent identity and use independent network family as uncertainty unit.
Predictors from pre-interaction state only: structural RAF/COT membership, cross-catalysis density, resource competition, parent stability, reaction diversity, raw reaction profiles, costed compressed predictive interfaces. Include finite-horizon locality or exact model baseline where appropriate. Compare identical held-out target and budget, account for model/support cost; no outcome leakage or posthoc thresholds. Primary test: incremental held-out predictive performance over strongest structural/kinetic baseline; null if no improvement. No claim of necessary universal mechanism.
Outstanding gates: independent review of all CA pilots; Rule54 published replication; AlChemy pinned reactor access and publication data/author clarification (Gmail draft saved, not sent at last confirmed state); full source and algorithm checks; frozen protocol with exact rates, seeds, budget and metrics. No new simulation, no automatic merge.
