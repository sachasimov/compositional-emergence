# Symmetry quotient pilot v1 — exploratory
Motivation: Rosas (2026), DOI 10.1126/sciadv.aeh0773, Corollary 1 and section Hierarchical organization under global symmetries. Global equivariance yields closed orbit coarse-grainings; this does not establish spatial individuals or closure under independent local transformations.
Use 15x15 toroidal B3/S23; two blinkers centered at (5,7),(5+d,7), d=3,4,5,6; all four equally probable horizontal/vertical phases; horizons 1,2,4. Same engineered fixtures as Life pilot, not held-out. For each case check all eight global square dihedral transformations commute with evolution at every horizon. Compute D4 canonical full-grid bitstring (rotations/reflections about grid center, no translation). Check that phase distinctions erased by this global quotient never split into distinct future global quotients within this sample; also verify directly by transforming each initial state. For independent local orientation quotient Z, canonicalize each fixed 3x3 initial window under its own D4 and concatenate. Predict Y=ordered pair of independently D4-canonical future windows; separately predict total future live population P. Report H(X), H(Z), H(Y), H(Y|Z), H(P|Z), H(Y|X) with X complete initial grid, and per-phase values. Expect global equivariance all cases, zero local quotient residual for separated blinkers; at d=3 local quotient can fail (no directional threshold). Exact ensemble entropy, not full coding cost. Fixed windows, phase labels only for generator, no discovered individuals or causal autonomy claim. Global and local targets differ: do not compare raw entropies as equivalent tasks. All cases retained. No independent audit, Stage C or confirmatory H4-H7. Stop after fixed 48 phase/horizon cases and 384 global transformation checks. Protocol and implementation committed before execution.
