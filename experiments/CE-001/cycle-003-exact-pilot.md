# Cycle 003 exact exploratory pilot v1

A bounded method sanity check, not a confirmatory CA experiment or H4 test. Enumerate all equally likely initial states of 8 binary cells, with identity dynamics, in three ensembles: independent bits; two independent four-bit constant blocks; one eight-bit constant block. Compare all contiguous intervals of width four (five candidates). Given a candidate's complete present state X, compare representation Z = first bit, to Y = complete candidate next state and Y2 = next first bit. Exact enumeration, base-2 entropy, no fitted parameters, no seeds. Report H(X), H(Z), H(Y|Z), H(Y2|Z), and H(Y) for every candidate. Candidate boundaries are supplied by exhaustive intervals, not discovered by a learned detector. Encoding cost excludes fixed interval geometry and shared model; therefore report ideal ensemble entropy, not executable compression size. Target Y2 is deliberately trivial negative control. Prediction loss measured by conditional entropy. Expected: the two planted homogeneous four-cell blocks uniquely attain zero residual for full target in two-block ensemble; in independent ensemble no interval attains zero; in global homogeneous ensemble all intervals tie. The first-bit target always has zero residual regardless of organization. Stop after 15 intervals. No CA dynamics, spontaneous discovery, intervention, physical autonomy, or independent review claimed. This pilot is exploratory and does not replace Cycle 002 benchmark or authorize Stage C.
