# Cycle 003 — causal perturbation pilot v1 (exploratory)
Question: can controlled perturbations recover static and dynamic units missed by passive history MI? Use 20x20 toroidal B3/S23. Fixtures: empty; isolated block; two blocks at top-left (7,5),(7,12); nearby blocks at (7,5),(7,8); single horizontal blinker centered (7,7); two distant horizontal blinkers centered (7,5),(7,12); glider with offsets (0,1),(1,2),(2,0),(2,1),(2,2) from (7,7); single isolated live cell (negative transient). Evaluate each at t=0,1,2,4,8, with one initial flip per lattice site (including dead sites) and unperturbed baseline. For each initially live site i, define directed response edge i->j for initially live site j != i if j differs from baseline at any of generations 1..h, h in [1,2,4,8]. Report weak components, mutual-edge components, geometry (8-neighbor components of initially live sites), number of responses outside initially live support, and complete per-flip response counts and support of changed cells per time for all 400 initial sites. Detector gets state only, not fixture labels; candidate universe is restricted to initially live sites and excludes dead structural support. Report every fixture and horizon; no threshold tuning. Compare static distant blocks (expected separate) and single block (expected connected by h=2), empty (abstain), singleton (not evidence of persistence); geometry comparison is required and no advantage is presumed. Moving patterns use fixed initial coordinates, not tracked identity. Perturbations are destructive, finite and conditional on baseline state, not general causal necessity. Outside-support responses and dead-site flips are diagnostics, not used for grouping. No spontaneous discovery, H4-H7 confirmation or independent audit. Stop after 8 fixtures x 400 flips x 8 generations; retain failed checks. Protocol committed before execution; bounded local compute only.
