# Compression versus integration: identifiability checkpoint
Provisional elementary deductions, not claimed novel. Let X be initial combined microstate, E fixed interaction context, Z=g(X) a pre-interaction descriptor and Y a predeclared future integration endpoint. If Z is predictively sufficient, I(Y;X|Z,E)=0. This is a property of a representation relative to the endpoint and context; it imposes no lower bound on P(Y=1). In the degenerate case where all outcomes are failure, a constant Z is sufficient, despite no integration. Likewise if all outcomes succeed. Therefore low prediction loss cannot alone be a monotonic predictor of success.
An exact autonomous pair of modules with no cross reactions can have trivial interface and no cross-dependent function. Adding a single cross reaction can create novelty or destroy viability depending on kinetics. Thus neither small interface nor nonzero coupling implies integration. These are counterexamples to sufficiency, not to a conditional statistical association.
Operationally keep three distinct measures: (i) pre-mixing model cost and held-out predictive loss for a standardized panel of perturbation responses, excluding actual integration outcome; (ii) retroactivity, distance between isolated and loaded module response under matched inputs; (iii) integration outcome evaluated on separate held-out mixing trajectories using persistent cross-parent products and selective ablation. Avoid circularity from learning an interface using the outcome it is meant to explain. Match parent viability, kinetic/resource parameters, reaction count, cross reaction rate, structural closure and opportunity. Compare exact lumping and full reaction profiles. Estimate incremental held-out performance by parent/network family, not correlated pair rows. A low-cost descriptor might improve sample efficiency without a causal role; causal test requires a controlled intervention changing interface complexity while holding relevant alternative mechanisms fixed, which may not be possible in all models. No universal conclusion from finite data.
